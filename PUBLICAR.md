# Publicar a página no GitHub

## Em um novo repositório

1. Crie um repositório na sua conta, com o nome sugerido `lattes-veterinaria`.
2. Envie o conteúdo deste pacote, preservando as pastas. O arquivo `README.md` deve ficar na raiz do repositório.
3. Confirme o envio dos arquivos. A apresentação será exibida na página inicial do repositório.

Estrutura esperada:

```text
README.md
PORTFOLIO.md
PUBLICAR.md
lattes-veterinaria/
  SKILL.md
  references/
    cadastro-e-casos-vet.md
    fontes-e-vigencia.md
    pontuacao-apcn-vet-2026.md
    qualificacao-ptt-quadrienal.md
    rastreabilidade.md
```

## Em um repositório existente

Preserve o README existente. Envie esta pasta como `lattes-veterinaria-github` e acrescente ao README principal:

```markdown
[Guia Lattes — Medicina Veterinária](lattes-veterinaria-github/README.md)
```

## Conferência final

Confira os links relativos após o envio e o nome da pasta da skill. Caso acrescente autoria, afiliação ou licença, use somente informações e permissões confirmadas pelo responsável pelo repositório. Este pacote não define uma licença de redistribuição em nome de terceiros.

A página usa o renderizador Markdown do GitHub. Não exige servidor, dependências, chave de API ou GitHub Pages. Nenhuma publicação remota é realizada ao extrair o pacote.
